# 구현 기준 요약

## A. 자발적 이전

- 온보딩 답변: 현재 매장에서 계속 영업 가능 = YES
- 비교: `현재 점포 Stay vs 후보지 Move`
- 현재 매장은 실제 선택지
- 각 후보는 현재 영업이익 유지에 필요한 매출/자금 기준으로 비교

## B. 비자발적 이전

- 온보딩 답변: 현재 매장에서 계속 영업 가능 = NO
- 비교: `후보 A vs 후보 B vs 후보 C`
- 현재 점포는 선택지가 아님
- 현재 매장 손익은 후보 A/B/C 계산의 기준점으로만 사용

## Rule → RAG

```text
초기 이전 소요자금
- 보유 가용현금
= 추가 필요 이전자금
        ↓
후보 자치구 + 카페 + 이전유형 + 영업상태
        ↓
정책금융 RAG
```

정책금융 결과는 자금부담 완화 가능성을 확인하는 근거이며, 실제 지원확정 금액으로 Rule 계산에서 차감하지 않는다.
