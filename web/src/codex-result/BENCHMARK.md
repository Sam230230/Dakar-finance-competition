# JOBDA 결과지 벤치마킹 메모

2026-09-01에 로그인된 실제 역량검사 결과 화면을 브라우저로 확인했다. 개인 결과 내용은 이 문서와 구현물에 복사하지 않았다.

## 확인한 구조

1. 결과 이력 카드에서 분석할 결과를 고른다.
2. `응시 점검 결과`, `기본 분석 결과`, `심층 분석 결과`의 세 탭으로 리포트 깊이를 나눈다.
3. 각 탭 첫머리에서 이 리포트의 용도와 읽는 법을 두 문장으로 안내한다.
4. 기본 분석은 유형 결론을 먼저 보여주고, 프로파일, 1순위부터 3순위 강점, 상세 가이드 순서로 내려간다.
5. 긴 본문은 좁은 단일 컬럼과 큰 흰색 카드로 묶는다. 오른쪽에는 결과 활용 CTA를 별도로 둔다.

## 실측한 토큰

- 외부 페이지 본문: Pretendard, 기본 12px / 400 / 1.4
- 분석 탭: 18px / 700 / 24px, 활성 배경 `#121619`, radius 8px, 높이 56px
- 리포트 본문 폭: 1,040px
- 읽는 법 카드: padding 42px 48px, border `1px solid #121619`, radius 16px
- 주요 섹션 카드: 내부 좌우 여백 48px 또는 80px, radius 8px 또는 16px, 그림자 없음
- 섹션 제목: 20px / 700 / 26px
- 반복 배경: `#FFFFFF`, `#F9F9FA`, `#EFFDF3`
- 핵심 초록: `#4BD667`, 보조 초록 텍스트 `#377538`
- 기본 글자: `#121619`, 보조 글자 `#44474B`, 약한 글자 `#9FA4AB`

| 결과 이력 카드 | 분석 대상 선택 | 후보 A, B, C 선택 카드 | 유지. 비교 대상을 바꾸는 장치로 전환했다. |

| 유형 결론 우선 | 사용자의 현재 상태 요약 | 추천 후보와 조건부 결론 | 유지. 결론을 맨 위에서 바로 확인하게 했다. |

| 우측 활용 CTA | 다음 행동 유도 | 하단 조건 변경 CTA | 변경. 결과를 읽는 동안 계속 떠 있으면 재무 판단을 방해해 하단으로 보냈다. |

## 가져오지 않은 것

- 결과 본문이 4,690px에 이르는 긴 한 장 구조는 그대로 쓰지 않았다. 후보 비교에서는 같은 수치를 반복하게 될 가능성이 크다.
- 세부 설명 대부분을 처음부터 펼쳐놓는 방식은 쓰지 않았다. 판단 종류별 탭으로 먼저 나눴다.
- 초록을 긍정 의미와 브랜드 장식에 동시에 쓰는 방식은 피했다. 구현본에서 초록은 충족과 선택에만 쓰고, 위험은 라벨과 아이콘을 함께 사용했다.
- 결과 화면 안의 개인 문장과 시각 자산은 복제하지 않았다. 구조와 실측 토큰만 참고했다.
